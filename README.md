# Machine Learning for Trading — 3rd Edition

Toy repository for exploring and implementing the concepts from
*Machine Learning for Trading, 3rd Edition* by Stefan Jansen.

This repository is a fork of the
[official Machine Learning for Trading repository](https://github.com/stefan-jansen/machine-learning-for-trading).

The original repository provides the notebooks, data infrastructure,
utilities, tests, and supporting code for the book. This fork is used as
a personal learning and experimentation environment.

## Purpose

The goal of this repository is to:

- work through the concepts presented in the book;
- reproduce and understand the experiments from the official repository;
- experiment with alternative implementations and ideas;
- develop a deeper understanding of machine learning for trading;
- use coding agents to assist with implementation while keeping the
  research methodology explicit and verifiable.

The official repository remains the reference implementation.
